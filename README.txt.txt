PROJECT: Secure Notes App

HOW TO RUN:

1. Go to backend folder
2. Run: npm install
3. Start MongoDB
4. Run: node server.js
5. Open frontend/index.html using Live Server

FEATURES:
- Login & Signup
- Encrypted Notes
- Create, Edit, Delete Notes
